# Tehkné Studio

Virtual Engineering Atelier by **Tehkné Solutions**.

S1.1 establishes the repository contract for the first executable workshop: Engineering Entity, Engineering Graph, semantic commands, observability, and the logical `.tks` project format.

## S1 Alpha benchmarks

- `DESKTOP-PC-001`: understand → break → diagnose → repair.
- `ARM-01`: control → automate → simulate → fail → redesign → make.

## Verify S1.1

```bash
npm run verify:s1.1
```

The web shell is scaffolded under `apps/studio-web`; S1.2 will materialize the first spatial workbench on that shell.
